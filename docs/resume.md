## 三、口头展开版(面试时用,不写进简历)

简历上是一句,被追问时展开成下面这些。每条都指向仓库里的具体位置。

**1. Agent Memory** —— 「动态注入」的具体机制是六槽位竞价:每步在 `窗口 − 输出预留 − 安全余量`
内**重建** prompt 而非追加,按硬下限 + 弹性系数 + 目标份额分配,余量优先流向**最不弹性**的槽位。
这两条规则共同保证检索记忆永不挤出角色人格与操作契约 —— 这是「分层记忆」类主张最常见的失效模式,
有专门回归测试。冲突解决用显式 `ConflictPolicy`,**默认置信度优先而非后写胜**:后写胜会让一次
幻觉抽取摧毁已验证的事实,这个默认值是被一次 0.3 置信度覆盖 0.95 置信度事实的真实故障改出来的。
记忆层有独立 precision@k / recall@k。压缩仅在 **step 边界**且占用 >70% 时触发,且在压缩不会实际
缩短时中止。**实测**:6k 窗口移除压缩使每步 token +15.7% 且额外驱逐 597 tokens,12k 以上效应消失。

**2. Agent MCP** —— `tools/list` → Python 模块编译链路(必需参数排序、标识符净化),Agent 在沙箱内
`import` 并用 `help()` 按需发现细节。工具选择是**双阈值门控**:IDF 加权覆盖率 + 绝对信息量,配
停用词表(小语料下 IDF 无法自行折扣停用词)。**实测**:188 tokens/步且与注册表规模无关;320 工具
时全量 schema 48,195 tokens —— 超出整个 32k 窗口,这是工具编译相对 schema 注入的硬理由。

**3. Skill** —— 原方案用 BM25 分数阈值,在小语料下会把「礼貌问候用户」判为相关技能:分数尺度本身
不可比,阈值没有含义。改用与工具同一套 IDF 覆盖率门控。上下文吃紧时技能槽**先丢正文保索引**,
Agent 仍知道自己有哪些技能可以再取。

**4. A2A** —— 权限模型是**一个不接受租户参数的函数** `may_delegate(source_id, target_id, *,
need_files)`:缺失即拒绝(无默认放行、无通配)、**租户是关系行上的列而非请求里的字段**(调用方
无法靠声明租户来授权跨租户委托)、授权有方向、文件传输是独立权限、自委托最先被拒。子 Agent 派生的
目的不是并行,而是**父级不必持有子级工作上下文**:子级获得全新 ledger、空历史与独立工作区子树,
父级只回收摘要与产物路径、**永不回收子级 transcript**。成本按 Agent 维度独立归属。

**5. 执行基底** —— Agent 唯一动作是在沙箱内写 Python:工具是可 `import` 的模块,中间产物落盘、
**仅 stdout 回流上下文**。该单一决策解决三件事:上下文增长由 Agent 的输出选择决定而非数据体量;
第 40 步可读第 3 步产物;崩溃恢复是重读工作区而非重放对话。收敛循环按**错误类别**而非消息文本
识别重复,反馈含被误用模块的真实签名;升级有界:同类两次 → 更强模型,三次 → 人工,之后中止。
**实测**:单份 10-K 全文 61,206 tokens,已超 32k 窗口 —— 这是该设计的前提。

**6. 沙箱与服务层** —— Docker `--network none` / 进程受限双后端,结果强制记录自身隔离级别;
容器 **10 项隔离属性由测试对活跃 daemon 逐条验证**。FastAPI 28 端点 + 每 run 一条 WebSocket;
运行记录只是索引不复制产物;Redis 会话带诚实的内存兜底;渠道 webhook 的验签与幂等**由路由统一
强制**,适配器无法遗漏。前端是运行观测台:每步 token 槽位分配的实时可视化。

**7. 评测体系** —— SEC XBRL **半自动构造真值集**(177 案例规模可行的原因,人工标注只能到几十条),
映射层解决四类数据陷阱。四类指标各自捕捉其余三者看不见的失效:数值准确率、**引用可验证率**
(数字对但引文不在原文 = 猜的)、**计算一致性**、**拒答正确性**。judge 报告自身 **Cohen's κ**,
低于 0.6 的维度从 headline 撤出。Harness 只在「无测试替身」**且**「确有真实 token 消耗」时才认定
为测量,否则标注 `NOT A MEASUREMENT`。**实测**:恒等式 177/177 误差 0.0;零模型地板线数值 0.571 /
引用 0.985 / 拒答 0.964;固化 workflow **0.738 硬天花板、26.2 点结构不可达** —— 模型节点只在未答出
时触发,答错的字段永不复查,**固化管道能修补遗漏,修不了错误**。
